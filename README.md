A premium, highly interactive corporate website and mobile PWA platform for **HS ONE STEP SOLUTIONS** built with **React 18**, **TypeScript**, **Vite**, and **Tailwind CSS**.

## 🚀 Live Demo & Deployment to Vercel

### Option 1: Deploy with Vercel (Recommended)
1. Push this repository to your GitHub account:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/hs-one-step-solutions.git
   git branch -M main
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your `hs-one-step-solutions` GitHub repository.
4. Framework Preset: **Vite** (Auto-detected).
5. Click **Deploy** — your live website will be generated in under 30 seconds!

## 🏛️ Core Features
1. **Interactive Blueprint Canvas**: Real-time CAD schematics and telemetry overlays.
2. **Skanvi-Style Sector Carousel**: Horizontal browsing strip across 12 specialized sectors.
3. **Interactive CAD Hospital Floorplan Explorer**: Clickable department hotspots (OT, ICU, MGPS, Radiology, Blood Bank, Dietary Kitchen) with live 3D room schematics.
4. **4-Step Project Builder**: Interactive wizard with real-time capacity and square footage sliders.
5. **Execution Model Comparison**: Dynamic comparison between fragmented 10-vendor coordination and unified HS One Step execution.
6. **Flagship 15-Stage Hospital Lifecycle**: Turnkey medical facility development from raw earth to statutory commissioning.
7. **Institutional Procurement Catalog**: Searchable B2B equipment catalog with multi-item BOQ builder.
8. **Live Project Telemetry Dashboard**: Simulation of client PMO tracking and QA sign-offs.
9. **Full Pure White Aesthetic**: Clean, pristine enterprise design matching the official brand logo.
